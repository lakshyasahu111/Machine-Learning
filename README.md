## 🎯 About This Repository

This is my public learning journal where I practice one ML algorithm each day and build a small project demonstrating it in action. The goal is to go beyond theory — every algorithm gets real data, real code, and a real use case.

By the end of this journey I aim to have hands-on experience with the full spectrum of ML — from simple linear models to deep learning architectures.

Each day folder contains:
- A Jupyter notebook with step-by-step explanation
- A clean Python script with the model
- The dataset or a download script
- A mini README with key takeaways


## 🛠️ Tech Stack

- **Language:** Python 3.10+
- **Core Libraries:** NumPy, Pandas, Scikit-learn, Matplotlib, Seaborn
- **Deep Learning:** PyTorch / TensorFlow (for later days)
- **Notebooks:** Jupyter Lab

## 📖 What I Cover Each Day

For every algorithm I aim to answer:

1. **What is it?** — Intuition in plain English
2. **How does it work?** — The math behind the scenes
3. **When should I use it?** — Strengths and weaknesses
4. **Show me the code** — Clean implementation from scratch *and* using scikit-learn
5. **Real project** — Applied to a dataset with results and visualizations
